Multimodal AI in the browser: Chrome Prompt API vs. Transformers.js

Compare Chrome’s built-in LanguageModel API and @huggingface/transformers running SmolVLM-256M-Instruct in a WebGPU Web Worker. Images and prompts stay on this device; preparing a provider may download model weights into browser storage.

Test double mode active — simulated provider adapters are running for automated UI verification, not real model inference.

5. Recorded comparison runs

Completed, cancelled, and failed runs stay in memory during this session so you can switch providers and compare results side by side. Responses render safe formatted Markdown on screen without raw HTML or external links; JSON export preserves raw response text, prompts, timings, cache condition, and metadata while excluding image bytes and original local filenames.

Differences reflect model weights, image preprocessing/patching, prompt templates, decoding defaults, and runtime together — not a controlled runtime benchmark.
